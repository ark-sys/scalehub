# Secrets

This folder is git-ignored except for this file. It holds everything the scalehub containers need to reach
Grid'5000:

```
enos/
├── Grid5000_creds.yaml   # username/password, created by ./deploy.sh generate
├── grid5000.pk           # SSH private key registered on Grid'5000
└── grid5000.pub
vpn/                      # personal Grid'5000 VPN files (.ovpn, .crt, .key)
scalehub, scalehub.pub    # generated by ./deploy.sh create, for IDE remote sessions
```

See [docs/getting-started.md](../../../docs/getting-started.md) for details.
